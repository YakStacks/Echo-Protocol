# Echo Protocol Threat Model

**Status: in progress.**

This document will enumerate threats and mitigations for Echo Protocol deployments, organized by the zero-trust posture stated in §7 of the specification: rogue node joining, capability packet spoofing, malicious AHP payloads (prompt injection at the task layer), sync-channel poisoning, and physical compromise of a public-site node.

Contributions and review welcome — particularly from researchers working on multi-agent system safety.
